# macprobe 业务需求

## 目标

在 Mac 上做开发或自动化的人，用一条命令确认当前终端或 IDE 是否已具备常用系统授权，在工具因权限失败之前知道缺什么。

## 检测项

| 检测项 | 已授予意味着 | 判定对象 | 授予位置 |
|---|---|---|---|
| 开发者工具 | 从该终端启动的、未经公证的本地程序可直接运行 | 启动本工具的终端或 IDE | 系统设置 › 隐私与安全性 › 开发者工具 |
| 完全磁盘访问 | 可读取受保护的个人数据（邮件、信息、其他应用数据） | 同上 | 系统设置 › 隐私与安全性 › 完全磁盘访问 |
| 辅助功能 | 可读取其他应用界面并模拟键盘鼠标 | 同上 | 系统设置 › 隐私与安全性 › 辅助功能 |
| 调试授权 | 调试其他程序时无需每次输入管理员密码 | 整台 Mac | 由管理员开启，无图形入口 |

- 同一台 Mac 换一个终端运行，前三项结果可能不同。
- 远程登录或后台运行时，前三项通常为“未授予”，不代表本地终端的情况。
- 完全磁盘访问以实际能否读取为准，而非设置中的勾选记录。

## 结论

每项给出三种结论之一：

- 已授予：系统明确允许
- 未授予：系统明确不允许，或尚未授权
- 无法判定：系统没有给出可识别的回答，需人工排查

## 约束

- 只读：不申请、不授予、不撤销权限，不弹授权窗口，不改系统设置
- 系统状态不变时，重复运行结果一致
- 装有企业安全软件的设备上，完全磁盘访问的检测可能触发安全告警
- 输出每项一条结论，人能直接读，程序能逐行解析；可选开启详细记录，用于排查
- 整体退出结果按最差一项计：无法判定（含用法错误）优先于未授予，未授予优先于全部授予
- 只支持两种用法：执行检测、查询版本；其他输入提示正确用法且不执行检测

## 非目标

- 不帮助授权或修复
- 不检测上述四项以外的权限（如相机、麦克风、屏幕录制）
- 不判定任意指定的应用
- 不常驻、不定时监控
- 不支持 macOS 以外的系统
